# Data source

The file `rodong_sinmun_en_sample.csv` is the **`rodong_sinmun_en`** corpus from the BA2 Digital Korea dataset menu.

- **Menu repository:** https://github.com/scdenney/ba2-final-paper-data
- **Path in menu repo:** `datasets/rodong_sinmun_en/rodong_sinmun_en_sample.csv`
- **Pinned commit:** `5d9f31b` (the commit the file was taken from — pin your own when you build your repo)
- **Rows:** 600 English-language *Rodong Sinmun* articles, 2018–2021
- **Upstream provenance and cleaning:** see the dataset `README.md` and `PREPROCESSING_NOTES.md` in the menu repo.

The CSV is included directly in this repository (it is small) so the analysis reproduces from a single clone. The pointer above records where it came from — that is the part that makes the data *findable* and *accessible* in the FAIR sense. If your corpus is large, you may instead keep only this `SOURCE.md` and not commit the CSV.
